# Bright Trail

A kid-friendly learning game built with React, TypeScript, and Vite. Designed for young children (ages 4+) with big touch-friendly UI, spoken prompts, playful sound effects, and five different mini-games:

- **Logic / Patterns** — "What comes next?" sequence completion
- **Shapes** — sort items from smallest to biggest
- **Attention** — spot the odd one out
- **Memory** — flip-card matching pairs
- **Math** — count and tap the right number
- **Puzzles** — shadow matching and "what goes together" categorization

## Getting started

```bash
npm install
npm run dev
```

Then open the printed local URL in your browser.

## Build

```bash
npm run build
npm run preview
```
